# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting/security contact mechanisms available for this repository when possible. If private reporting is unavailable, contact the maintainer privately through the GitHub profile before public disclosure.

Do not include credentials, private keys, personal data, or other sensitive information in reports.

## Scope

Security reports are welcome for issues in the NetScope application, its build configuration, and repository automation.

NetScope does not intentionally require API keys or user accounts for its core diagnostic features.
