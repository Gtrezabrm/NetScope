# NetScope 🌐

**ابزار تشخیص و بررسی کیفیت شبکه و DNS برای اندروید**

NetScope یک ابزار متن‌باز و Android-first است که برای بررسی واقعی کیفیت، پایداری و دسترسی اتصال اینترنت طراحی شده است؛ با تمرکز ویژه بر شرایط واقعی شبکه و ارتباطات موردنیاز برای بازی‌ها.

> ساخته‌شده توسط **Gtrezabrm** با تمرکز بر اندازه‌گیری واقعی، توضیح شفاف نتایج و پرهیز از ادعاهای غیرقابل اثبات درباره پینگ بازی‌ها.

## ✨ قابلیت‌ها

### 🧪 بنچمارک DNS

- ارسال مستقیم درخواست‌های واقعی DNS به Resolver انتخاب‌شده.
- اندازه‌گیری تأخیر، Median، Jitter، حداقل و حداکثر تأخیر، Packet Loss و میزان پایداری.
- استفاده از چند دامنه برای کاهش تأثیر پاسخ‌های خاص یا کش‌شده.
- رتبه‌بندی بر اساس ترکیبی از سرعت و پایداری، نه فقط کمترین عدد تأخیر.
- جدا کردن DNSهای ناپایدار یا غیرقابل‌دسترسی از گزینه‌های قابل اعتماد.
- پشتیبانی از DNS سفارشی و DNSهای IPv6 در صورت امکان.

### 📶 تشخیص وضعیت شبکه

- نمایش وضعیت فعلی اتصال و نوع شبکه.
- نمایش اطلاعات IPv4، IPv6 و DNS فعلی در صورت در دسترس بودن.
- کمک به تشخیص اینکه مشکل بیشتر مربوط به DNS است یا خود اتصال اینترنت.
- بررسی دسترسی DoH و DoT/TLS.

### 🎮 بررسی ارتباطات Gaming

NetScope ادعا نمی‌کند که اتصال TCP به یک میزبان عمومی همان پینگ واقعی داخل بازی است.

در عوض، بخش Gaming اتصال TCP و مسیر ارتباطی را به‌صورت شفاف بررسی می‌کند و موارد زیر را نشان می‌دهد:

- Latency
- Jitter
- Connection Loss
- تست Host/IP و Port دلخواه
- مقصدهای عمومی کاربردی مانند Steam و Epic Games

نتایج این بخش **شاخص وضعیت اتصال شبکه** هستند و به معنی تضمین پینگ داخل بازی یا دسترسی به سرورهای بازی نیستند.

### 📊 نتایج و تاریخچه

- نمایش جزئیات کامل نتایج DNS
- نمایش جزئیات تک‌تک درخواست‌ها
- مقایسه چند DNS با یکدیگر
- کپی آدرس DNS و گزارش کامل تست
- ذخیره محلی تاریخچه تست‌ها

## 🎯 چرا NetScope ساخته شد؟

کیفیت اینترنت را نمی‌توان با یک عدد Ping خلاصه کرد.

ممکن است یک DNS تأخیر بسیار کمی داشته باشد، اما بخش بزرگی از درخواست‌هایش را از دست بدهد. همچنین ممکن است DNS کاملاً سریع باشد ولی خود مسیر اینترنت دارای Jitter یا ناپایداری باشد.

ایده اصلی NetScope ساده است:

**چیزی را که واقعاً اتفاق افتاده اندازه بگیر، معنی نتیجه را واضح توضیح بده و بیشتر از چیزی که تست می‌تواند ثابت کند ادعا نکن.**

## 🔬 روش اندازه‌گیری

NetScope تلاش می‌کند نتایج قابل فهم و قابل بررسی باشند:

- **DNS Latency:** زمان بین ارسال درخواست DNS و دریافت پاسخ متناظر.
- **Packet Loss:** درصد درخواست‌هایی که در محدوده زمانی تست پاسخ معتبر دریافت نکرده‌اند.
- **Jitter:** میزان تغییرپذیری زمان پاسخ‌های موفق DNS نسبت به میانگین.
- **TCP Latency:** زمان لازم برای برقراری اتصال TCP به مقصد و Port انتخاب‌شده.
- **Timeout الزاماً به معنی بسته بودن Port نیست.** Timeout می‌تواند ناشی از فیلترینگ، مشکل مسیریابی یا در دسترس نبودن مقصد باشد.

NetScope برای محاسبه تأخیر DNS از یک سرور واسط ساختگی استفاده نمی‌کند.

## 🔐 حریم خصوصی و امنیت

NetScope به‌عنوان یک ابزار تشخیص محلی طراحی شده است.

- برای استفاده از قابلیت‌های اصلی نیازی به حساب کاربری نیست.
- برای تست‌های اصلی نیازی به API Key نیست.
- تاریخچه تست‌ها به‌صورت محلی روی دستگاه ذخیره می‌شود.
- فقط مجوزهای شبکه موردنیاز برای قابلیت‌های تشخیصی استفاده می‌شوند.
- قابلیت تغییر DNS یا VPN داخلی ندارد.
- ادعایی درباره دور زدن محدودیت‌های شبکه ندارد.

## 🧩 فناوری‌ها

- Flutter / Dart
- معماری Android-first
- دریافت اطلاعات شبکه اندروید از طریق Platform Channel
- تست مستقیم UDP DNS در پلتفرم‌های پشتیبانی‌شده
- تست ارتباط TCP
- ذخیره محلی تنظیمات و تاریخچه
- رابط فارسی RTL با تایپوگرافی Vazirmatn و Lalezar

## ⚠️ محدودیت‌های مهم

NetScope یک ابزار تشخیصی است و نمی‌تواند عملکرد یک برنامه یا بازی را تضمین کند.

موفق بودن اتصال به یک میزبان عمومی ثابت نمی‌کند که تمام سرویس‌ها، CDNها، سرورهای بازی یا مسیرهای شبکه در دسترس هستند. به همین شکل، شکست یک تست به یک مقصد مشخص نیز ثابت نمی‌کند که کل سرویس مسدود است.

بنابراین نتایج Gaming باید به‌عنوان **شاخص وضعیت ارتباط شبکه** تفسیر شوند، نه پینگ قطعی داخل بازی یا تضمین دسترسی به Matchmaking.
