# 🌐 نت‌اسکوپ | NetScope

> **یک ابزار Android-first برای بررسی واقعی DNS و وضعیت شبکه؛ برای اندازه‌گیری، نه حدس زدن.**

## 💡 چرا NetScope ساخته شد؟

وقتی اینترنت کند یا ناپایدار می‌شود، معمولاً اولین چیزی که تغییر می‌دهیم DNS است. اما بدون اندازه‌گیری دقیق، نمی‌توان فهمید مشکل واقعاً از DNS است یا از مسیر و کیفیت خود اتصال.

**NetScope برای همین ساخته شده است: به‌جای حدس زدن، اندازه‌گیری کنیم.**

این برنامه وضعیت **اتصال فعلی کاربر** را بررسی می‌کند و فقط چیزی را گزارش می‌دهد که واقعاً قابل اندازه‌گیری است. زمان پاسخ DNS را با Ping داخل بازی اشتباه نمی‌گیرد و یک مقصد عمومی TCP را هم به‌عنوان سرور بازی معرفی نمی‌کند.

## ✨ قابلیت‌ها

### 🌐 تست و Benchmark DNS

- ارسال مستقیم Queryهای DNS به Resolver انتخاب‌شده روی `UDP/53`
- اندازه‌گیری زمان واقعی پاسخ DNS
- نمایش میانگین، Median، کمترین و بیشترین زمان
- محاسبه Jitter، نرخ موفقیت و نرخ شکست درخواست‌ها
- ثبت استفاده از Primary و Secondary
- امتیازدهی و رتبه‌بندی با تأکید جدی بر پایداری
- پیشنهاد بهترین DNS برای **اتصال فعلی کاربر**

### ⚡ تست سریع

برای زمانی که فقط یک بررسی فوری لازم دارید، Quick Test بدون اجرای Benchmark کامل در دسترس است.

### 📡 وضعیت شبکه

NetScope اطلاعاتی را که Android از اتصال در اختیار برنامه قرار می‌دهد نمایش می‌دهد، از جمله:

- وضعیت آنلاین یا آفلاین بودن
- نوع اتصال
- اعتبارسنجی اینترنت
- اطلاعات IPv4 و IPv6
- DNS فعلی

### 🎮 Gaming و TCP Connectivity

NetScope عمداً زمان اتصال TCP را **Ping داخل بازی** نام‌گذاری نمی‌کند.

در این بخش اتصال TCP به چند مقصد عمومی و سرویس گیمینگ، از جمله **Steam** و **Epic Games**، بررسی می‌شود. همچنین کاربر می‌تواند Host/IP و Port دلخواه خود را وارد کند.

نتیجه اتصال به شکل شفاف نمایش داده می‌شود:

- 🟢 **باز** — اتصال TCP پذیرفته شده است.
- 🔴 **ردشده / بسته** — مقصد اتصال را صریحاً رد کرده است.
- 🟡 **بدون پاسخ / احتمال فیلتر** — در بازه تست پاسخ قابل اتکایی دریافت نشده است.
- ⚪ **خطای اتصال** — خطای دیگری هنگام برقراری اتصال رخ داده است.

> ⚠️ صرفاً Timeout شدن یک تست به معنی بسته بودن قطعی Port نیست.

### 🧠 سلامت اتصال

یک خلاصه ساده از وضعیت اندازه‌گیری‌شده شبکه تا کاربر برای فهمیدن نتیجه مجبور نباشد همه جزئیات فنی را بررسی کند.

### 🔬 تشخیص‌های پیشرفته

- بررسی DNS روی IPv6
- بررسی دسترسی DoH
- بررسی DoT و TLS روی پورت 853

### 📊 نتایج، مقایسه و تاریخچه

- جزئیات کامل نتیجه هر DNS
- جزئیات تک‌تک نمونه‌ها
- مقایسه چند DNS
- کپی DNS و گزارش کامل
- ذخیره تاریخچه محلی تست‌ها
- پاک کردن تاریخچه

### 🎨 رابط کاربری

- رابط فارسی و کاملاً RTL
- حالت روشن، تاریک و هماهنگ با سیستم
- داشبورد ساده و خلوت
- جزئیات حرفه‌ای در صفحات جداگانه

## 🧪 فلسفه اندازه‌گیری

در NetScope عمداً بین انواع اندازه‌گیری تفاوت گذاشته شده است:

| نوع تست | معنی |
|---|---|
| DNS Latency | مدت زمان دریافت پاسخ DNS |
| DNS Reliability | میزان ثبات دریافت پاسخ از DNS |
| TCP Latency | مدت زمان برقراری اتصال TCP |
| TCP Connectivity | امکان برقراری اتصال TCP با مقصد آزمایش‌شده |
| ICMP Ping | توسط تست‌های DNS و TCP این برنامه ادعا نمی‌شود |
| In-game Ping | بدون مقصد معتبر سرور بازی ادعا نمی‌شود |

نتایج به ISP، مسیر شبکه، شرایط لحظه‌ای اتصال، مقصد تست و زمان آزمایش وابسته‌اند.

## 🔐 امنیت و حریم خصوصی

NetScope برای قابلیت‌های اصلی خود به حساب کاربری، API Key یا سرور واسطه اندازه‌گیری نیاز ندارد.

مجوزهای Android عمداً محدود نگه داشته شده‌اند:

- `INTERNET` — برای تست‌های شبکه
- `ACCESS_NETWORK_STATE` — برای خواندن وضعیت شبکه Android

Cleartext HTTP و Backup برنامه نیز در تنظیمات Android غیرفعال شده‌اند. هیچ API Key، Token، Password یا Private Signing Key نباید وارد Repository شود.

برای انتشار عمومی، کلیدها و اطلاعات امضای Release باید خارج از Repository و به‌صورت امن در محیط Build نگهداری شوند.

## ⚠️ محدودیت‌های مهم

- نتایج اندازه‌گیری محلی هستند و رتبه‌بندی جهانی محسوب نمی‌شوند.
- DNSای که امروز سریع است ممکن است فردا بهترین گزینه نباشد.
- DNS Latency با ICMP Ping یکی نیست.
- TCP Connectivity با Latency واقعی سرور بازی یکی نیست.
- موفقیت اتصال به Steam یا Epic Games ثابت نمی‌کند که همه سرویس‌ها یا سرورهای بازی در دسترس هستند.
- Timeout به‌تنهایی بسته بودن قطعی Port را ثابت نمی‌کند.
